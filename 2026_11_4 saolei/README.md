# 控制台扫雷游戏

一个用 C 语言写的控制台扫雷小游戏，使用 Visual Studio 2026 开发，适合 C 语言初学者阅读和学习。是我作为小白学习C语言使用dsh帮我做出的小游戏，目的是使我拥有更强的阅读代码能力，并且让我学习更多的知识

## 功能

- 三档难度：初级 9x9（10 雷）、中级 16x16（40 雷）、高级 16x30（99 雷）
- 首击保护：第一次翻开的格子及周围 8 格保证没有地雷
- 空白区域自动扩散
- 插旗 / 取消旗
- 彩色数字、剩余雷数显示
- 胜利 / 失败判定，失败时显示地雷和插错的旗
- UTF-8 中文输出，带详细中文注释

## 编译运行

1. 用 Visual Studio 2026 打开 `dsh_2026_11_4saolei test.slnx`
2. 选择 `x64` / `Debug`
3. 按 `Ctrl + F5` 运行

## 操作说明

- 输入 `1`：翻开格子
- 输入 `2`：插旗 / 取消旗
- 输入 `0`：结束当前局，返回主菜单
- 再输入行、列，例如 `3 5`（从 1 开始）

把除地雷外的所有格子都翻开即获胜；踩到地雷则失败。
