## 题目

1. **阶梯电价**：月用电量 50 kW·h 以内（含 50）电价 0.53 元/kW·h，超过 50 的部分每 kW·h 上调 0.05 元；
   输入月用电量，输出应付电费；用电量小于 0 时输出 `Invalid Value!`。
3. **序列求和**：输入两个正整数 m、n（0<m≤n），求 `Σ(i² + 1/i)`（i 从 m 到 n）。
4. **交错序列前 n 项和**：输入正整数 n，求 `1/1 - 2/3 + 3/5 - 4/7 + 5/9 - 6/11 + ...` 的前 n 项之和。
5. **平方根求和**：输入正整数 n，计算 `1 + √2 + √3 + ... + √n`，保留 2 位小数。
6. **求给定序列前 n 项和**：输入正整数 n，求 `e = 1! + 2! + 3! + ... + n!`，
   要求定义并调用函数 `fact(n)` 计算 n!，函数类型是 `double`。

> 题号沿用作业原文（原文没有需要提交的第 2 题）。

## 代码要点

| 题 | 关键点 |
|---|---|
| 1 阶梯电价 | 先判 `x<0`；超过 50 的部分按 `(x-50)*(0.53+0.05)` 算，不是整段都按 0.58；注意 `Invalid Value!` 的大小写 |
| 3 序列求和 | `1.0/i` 不能写成 `1/i`（整数除法会得 0）；循环从 m 到 n |
| 4 交错序列 | `flag` 正负交替；`(double)flag` 保证按小数计算 |
| 5 平方根求和 | `#include <math.h>` + `sqrt()`；`%.2f` 保留两位小数 |
| 6 阶乘求和 | 累乘变量 `product` 初值必须是 `1`，写成 `0` 的话结果永远是 0 |
